## Sobre este repositório

O conteúdo é gerado e publicado automaticamente pelo sistema interno da escola e servido pelo GitHub Pages.
Alterações feitas diretamente aqui são substituídas na publicação seguinte.

| Arquivo | Conteúdo |
| --- | --- |
| `index.html`, `assets/` | Páginas, estilos, scripts e fontes do site |
| `content.json` | Textos, cursos e vitrine; os dados da área do aluno ficam cifrados |
| `img/`, `m/`, `v/` | Imagens da vitrine, materiais públicos e arquivos da área do aluno (cifrados) |
| `favicon.ico`, `icon-*.png`, `site.webmanifest` | Ícones e configuração para navegadores e celulares |

## Segurança e privacidade

- Site estático: sem banco de dados, sem formulários que enviem dados e sem ligação com os sistemas internos da escola.
- A área do aluno é protegida por criptografia de ponta a ponta (AES-256-GCM, com chave derivada da senha do aluno por PBKDF2). Sem a senha, o conteúdo é ilegível, e nenhum dado pessoal aparece em texto neste repositório.
- Política de segurança de conteúdo (CSP) com Trusted Types e nenhum serviço de terceiros.
